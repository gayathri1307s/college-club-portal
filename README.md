# College Club Portal 🎓

A web-based portal developed to showcase college club activities, display events, and manage student registrations for various competitions and club events.

## ✨ Features

- **Event Listing:** Displays college events and activities.
- **Club Information:** Dedicated pages for different events and clubs.
- **Student Registration:** PHP-based registration forms for event participation.
- **Login Page:** Provides a login interface for users.
- **Database Integration:** MySQL connectivity for storing registration details.
- **Visual Interface:** Images and assets to present college events and activities.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Development:** XAMPP

## 🚀 Getting Started

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone this repository into the XAMPP `htdocs` directory.
3. Start **Apache** and **MySQL** using the XAMPP Control Panel.
4. Create a MySQL database named `college_club`.
5. Configure the database connection settings in the PHP backend files to match your local MySQL setup.
6. Open the project in your browser through your local XAMPP server.

## ⚠️ Notes

- This project is intended for learning and demonstration purposes.
- Database setup and configuration may be required before the application works locally.
- Do not use local development database credentials on a production server.
